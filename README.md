# Crushed Can — Science Visualisations

Open `index.html` directly in a browser. No build tools, dependencies or server are required.

## Controls

- **Turn heater ON/OFF:** works with the lid either on or off.
- **Put lid ON / Take lid OFF:** changes between open and closed heating.
- **Dunk in cold water:** simulates inversion into cold water, which seals the opening while steam condenses.
- **Reset:** returns to the initial state.

No prediction or answer entry is required before interacting.

## Teaching model

When heating with the lid off, steam can escape and displace air, so fewer *illustrative* gas particles remain visible while movement speeds up. When heating with the lid on, particles cannot escape, so pressure rises; the lid pops off at a model threshold. When the heated can is cooled with its opening sealed by water, steam condenses, gas pressure falls, and the can may collapse under external atmospheric pressure.

This is an intentionally **qualitative** simulation, not an ideal-gas or fluid-dynamics solver. The displayed particle dots are illustrative, not exact molecule counts. Real experiments require adult supervision and appropriate safety precautions.
